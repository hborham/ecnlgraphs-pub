BeatWin = direct win, arrow weighted by goal difference · BeatPath = chain of BeatWins · Broken BeatLoop = a win cycle resolved by removing its weakest link · Draws create no link. Only the smallest set of arrows is drawn: an arrow is omitted when a BeatPath through other teams already implies it.
